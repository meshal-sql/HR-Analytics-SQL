# HR Analytics Project (SQL)

## Project Overview
This project analyzes HR employee data using SQL to extract insights about salaries and departments.

## Analysis Done
- Total employees count
- Average salary
- Highest and lowest salary
- Department-wise analysis
- Salary classification (High / Medium / Low)

## Tools Used
- SQL

## Key Insights
- IT department has higher salaries
- HR department has lower salaries
- Salary distribution analyzed successfully

## Conclusion
This project demonstrates basic data analysis skills using SQL.
